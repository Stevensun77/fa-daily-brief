# IG 圖文卡片視覺風格設計

## 背景與目標

`fa-daily-brief` 目前每天自動產出 `daily/YYYY-MM-DD.md`(新聞摘要)與 `ig/YYYY-MM-DD.md`(三段式 IG 文案:案例導入 / 解決做法 / CTA 導流 LINE)。這兩個檔案都只有文字,還沒有變成可以直接發文的視覺圖卡。

本設計要解決的是:定義一套固定的卡片視覺模板(顏色、字體、版面),讓每天的 IG 文案可以套用同一套模板產出圖片,而不用每篇重新設計。本階段**只做風格與架構設計,不含 AI 生圖**——經過討論,目前卡片走純排版路線(HTML/CSS + 截圖),AI 插畫/照片背景(Gemini Nano Banana)刻意不在本次範圍內,原因是:(1)不需要額外安裝 `google-genai` 套件與申請 `GEMINI_API_KEY`;(2)品牌偏好的「深色幾何、霧面質感」用純排版就能做出高級感,不依賴 AI 生圖。

## 卡片架構

每篇 IG 貼文是一組輪播圖卡,由 3 種卡片樣板組成,套用 `ig/YYYY-MM-DD.md` 裡的三段式文案:

| 卡片類型 | 內容來源 | 張數 |
|---|---|---|
| 封面卡 | 案例導入(Hook)的開場句 | 固定 1 張 |
| 內文金句卡 | 每張最上方放一句金句(從內文段落挑最有力的一句話,單獨用金色強調),下方接該段落的支持內文 | 2~4 張,依當天文案長度彈性決定 |
| CTA 卡 | 收尾的 LINE 導流呼籲句 | 固定 1 張 |

同一套版型重複套用不同文字內容,不重新設計版面。

## 視覺設計 Token

### 底色(依新聞焦點領域對應,4 組色調 + 1 組預設)

`fa-daily-brief` 的 `CLAUDE.md` 定義了 5 大焦點領域,其中 4 個對應到冠弘既有的品牌色偏好(深海軍藍、鐵灰、深綠、深棕),「社會大小事」沒有專屬色,預設使用投資管理的深海軍藍。以下色碼為**暫定值**,之後確認最終色碼後只需更新這張表,不用改版型:

| 焦點領域 | Token | 暫定色碼 |
|---|---|---|
| 投資管理 | `color-bg-investment` | `#0f1620`(深海軍藍) |
| 風險管理與保險 | `color-bg-insurance` | `#16181c`(鐵灰霧面) |
| 收支與理財 | `color-bg-finance` | `#10201a`(深綠霧面) |
| 資產傳承與稅務 | `color-bg-legacy` | `#1c140f`(深棕霧面) |
| 社會大小事(預設) | 沿用 `color-bg-investment` | `#0f1620` |

### 文字與強調色(4 組主題共用)

| Token | 色碼 | 用途 |
|---|---|---|
| `color-text-primary` | `#f5f3ee` | 標題、CTA 主文字(米白) |
| `color-text-body` | `#c7cdd6` | 內文段落次要文字(淺灰藍) |
| `color-accent-gold` | `#c9a86a`(線)/ `#e8c98a`(金句文字) | 金句強調、底部分隔線 |
| `color-text-meta` | `#6b7480` | IG 帳號、頁碼(底部小字) |

### 字體

| Token | 字體 | 用途 |
|---|---|---|
| `font-heading` | Noto Sans TC,weight 900 | 封面卡標題(黑體,現代、適合快速滑動閱讀) |
| `font-body` | Noto Sans TC,weight 400~700 | 金句、內文段落、CTA 文字 |

字體透過 Google Fonts CDN 載入(`family=Noto+Sans+TC:wght@400;500;700;900`)。

### 尺寸與間距(以輸出實際尺寸 1080 × 1350px 為基準)

| Token | 數值 | 說明 |
|---|---|---|
| `card-size` | 1080 × 1350px(4:5) | IG 輪播圖片實際輸出尺寸 |
| `content-margin` | 約 86px | 左右邊界,金線、底部列(IG 帳號/頁碼)都對齊這個邊界,不頂到卡片邊緣 |
| `headline-size` | 約 97px | 封面卡標題字級 |
| `quote-size` | 約 68px | 內文金句字級 |
| `body-size` | 約 45px | 內文段落字級 |
| `cta-text-size` | 約 58px | CTA 卡主文字字級 |
| `cta-line-size` | 約 65px | CTA 卡導流句字級 |
| `meta-size` | 約 36px | 底部 IG 帳號、頁碼字級 |

以上尺寸換算自風格確認階段的 300px 寬度 mockup(比例尺 3.6),實作時可依 Playwright 實際渲染結果微調,不必完全照搬。

## 各卡片版面規則

**封面卡**
- 標題整張垂直置中,不放任何頂部標籤文字(已確認拿掉「財務顧問手記」字樣)。
- 標題下方 52px(mockup 比例)處放一條金色分隔線,線的左右邊界對齊 `content-margin`(貼齊底部文字邊界,不是短線置中、也不是頂到卡片邊緣)。
- 底部固定列:左邊 `@sghongfire`,右邊頁碼,格式為 `01 / 05` 這種數字文字型。

**內文金句卡**
- 左上角放一個裝飾性引號符號。
- 金句(金色、加粗)置於卡片上半部。
- 金句下方接該段落的內文(淺灰藍色、靠左對齊,一般粗細)。
- 底部固定列同封面卡:`@sghongfire` + 頁碼。

**CTA 卡**
- 上半部放收尾呼籲文字(米白色)。
- 下半部放導流 LINE 的關鍵句(金色、加粗、置中)。
- 底部固定列同上。

底部固定列(`@sghongfire` + 頁碼)三種卡片都共用同一組樣式與位置,是唯一跨卡片重複的固定元素。

## 產出流程

1. 確認當天 `ig/YYYY-MM-DD.md` 文案內容無誤(沿用現有排程產出的草稿)。
2. 依三種樣板與文案內容,產生對應的 HTML 檔案,套用當篇新聞所屬焦點領域的底色 token。
3. 用 Playwright 對每個 HTML 檔案截圖,輸出 1080 × 1350px 的 PNG。
4. 圖片存到 `ig/YYYY-MM-DD/` 資料夾,依卡片順序命名,例如 `01-cover.png`、`02-quote.png`……`05-cta.png`。
5. **此步驟為手動觸發**,不接入每天 07:03 的自動排程。理由與現有文字草稿流程的原則一致:圖文比純文字更難自動判斷排版是否跑掉(文字截斷、對齊跑版等),所以先由冠弘看過文案確認後,再手動請 Claude 出圖。之後若用習慣、想要全自動出圖,再另外討論是否接入排程。

## 日後更新複雜度

- **改顏色 / 字體 / 間距**:只改對應 token 的值,3 種卡片樣板會同步套用,複雜度低。
- **改內容架構**(例如三段式改四段式、卡片張數規則調整):需調整樣板的分頁邏輯與文案對應規則,複雜度中等,但仍是改一次規則、之後每天套用。
- **全面改版**(例如從深色系整個換成淺色系):等於重新設計一輪版型與 token,複雜度較高,但預期不常發生。

## 範圍外(Out of scope)

- AI 生成插圖/照片背景(Gemini Nano Banana / `ai-artist` skill)——刻意排除,見「背景與目標」說明。
- 自動發布到 IG——本設計只做「產出圖片」,不含將圖片實際發佈到 Instagram 的流程。
- 接入每日自動排程——圖片產出目前手動觸發,見「產出流程」第 5 點。
