# IG 圖文文案檢查清單

寫完文案後,對照這 5 點自我檢核,每篇至少要有 4 項打勾才算合格。

## 1. 前 3 秒鉤子
- [ ] 開頭第一句(或第一張圖卡)能不能讓人停下滑動?
- [ ] 有沒有避免直接複述新聞標題?
- [ ] 是不是用提問句或具體情境開場,而不是知識性陳述?

## 2. 儲存 / 分享導向(乾貨感)
- [ ] 內容是否包含「可以馬上照做」的具體清單或步驟?
- [ ] 有沒有明確理由讓讀者想「存起來之後用」,而不是看完就滑走?
- [ ] 資訊密度是否夠高,一眼看得出「這篇有料」?

## 3. 人設感 > 機構感
- [ ] 是否有具體情境或案例(去識別化過的客戶故事、真實觀察),而不是純知識科普?
- [ ] 語氣是不是像「一個具體的人在跟你說話」,而不是機構公告?
- [ ] 有沒有帶一點個人觀點或立場,而不是中立轉述新聞?

## 4. 穩定頻率與可預期性
- [ ] 是否符合固定欄目/系列的節奏(例如每週固定主題)?
- [ ] 發文時間是否維持穩定,讓粉絲有預期感?

## 5. CTA 具體但不生硬
- [ ] 結尾是否有明確的下一步(加 LINE、私訊等),而不是空泛結尾?
- [ ] 語氣是否維持「朋友提醒」而非「業務推銷」?
- [ ] CTA 門檻是否夠低(例如「歡迎問我」而非「立即購買」)?

---

## 已知限制

這份清單是根據社群內容行銷的公開通則整理,不是特定平台數據或你帳號的實測結果。實際成效仍需靠你自己 IG 後台的洞察報告(觸及、儲存、分享、私訊數)持續校正,清單只是起點,不是保證。
